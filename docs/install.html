安装准备

只适用于已经实测的小米 AI 音箱 MDZ-25-DA（S12A）。本页只列仓库里写明的准备和顺序，分区写入命令以操作手册为准，这里不另写一套。

开始前确认

  • 音箱是你自己的，或你已经获准改动。
  • 型号是 MDZ-25-DA / S12A。其他型号没有测过。
  • 准备十字螺丝刀、USB-TTL（文档举例 CH340）、SH1.0 转 2.54 mm 杜邦 3P 线。
  • 准备所选大模型的 API 密钥。密钥放在音箱的私有配置里，不要提交进仓库。
  • 如果要自己编译音箱端 EdgeTTS，开发电脑还需要 Rust、Zig 和 cargo-zigbuild。不编译这一档就可以先不装。

串口，不用焊接

打开后盖后，主板上有现成的 JST 串口插座。模块 TX 接音箱 RX，模块 RX 接音箱 TX，GND 共地。波特率 115200 8N1。不要连接 USB-TTL 的 5V 或 3.3V。不要只按线色判断针脚，先用万用表量过。

主板插座位置和线材说明在 设备与准备 和 从零接入。

SSH 会动到系统分区

这不是刷一套第三方固件来接管音频。小爱原来的识别和家电控制要留下来。SSH 还没有时，手册要求往系统分区写入启动脚本，dropbear 才会启动。boot1 手册记录过用 mtd 写 system1。写错可能导致无法启动，串口是救援通道。设备已经能 SSH 时，不要为了照抄再写一遍分区。

  • boot0 SSH 手册
  • boot1 SSH 手册

SSH 之后

  1. 按 跑通第一轮对话 上传客户端，填写 /data/native_first.env。
  2. 要让电脑不必在回答时开着，使用 LLM_PIPELINE=native 和 TTS_ENGINE=device。示例配置里 TTS 默认是 server，那需要一台 TTS 服务在线。
  3. 第一轮先验证原生命令、天气，再验证大模型。追问和首轮停顿续说是后面的可选组件，见 逐步完善对话。
