# DeepSeek 联网搜索

音箱 native 主线保留 `deepseek-flash`，在回答前结合同一会话决定是否搜索。搜索与网页读取使用 DeepSeek 官方接口，直接从音箱发起，不依赖 Mac；小爱原生先处理家控、闹钟、天气、报时等已有能力。

## 使用规则

| 问题 | 行为 |
|---|---|
| “帮我搜一下这家公司”“核实一下这个消息” | 搜索 |
| 现价、营业状态、比赛结果、新闻、新产品与近期变化 | 依语义搜索，不要求出现“最新” |
| “那另一款多少钱？” | 结合当前会话补全对象，重新搜索 |
| “把刚才的回答缩短” | 使用当前会话直接回答 |
| 稳定知识、创作、翻译、闲聊 | 直接回答 |
| “帮我写今天的日记”或翻译含“搜索”的引文 | 直接回答，不按词语机械触发 |
| 要求总结一个给定的公共网页链接 | 读取该网页 |
| “不要联网，解释搜索引擎” | 直接回答 |
| 缺少必要对象且上下文无法补全 | 先询问对象 |

规则通过一次非思考模式的结构化模型判断执行。判断只读取当前请求携带的会话，不检索其它会话；换话题后的新 session 不带旧上下文。语义判断并非完全确定，用户可通过“帮我联网搜索……”明确表达意图。

## 回答、来源和失败

搜索返回最多三条网页，向回答模型提供标题、网址、发表日期和摘要。指定网页提供正文；外部资料作为数据，不执行其中的命令，也不据此发起下一次工具调用。回答需要核对日期，资料不足或矛盾时应说明无法确认。

语音简短说明来源机构、网站或文章及相关日期，不要求朗读长网址；提问本身需要接口地址等网址时仍可回答。原始来源网址记录于 `/tmp/native_first_client.log` 的 `[WEB] source=` 行；不新增完整网页的持久缓存。

网络超时、鉴权失败、余额不足、空结果、无效判断或无可用正文时，客户端直接生成固定提示“暂时无法联网查询，请稍后再试。”，不调用最终回答模型猜测实时事实。判断失败也采用同一提示；不会静默切换到纯聊天。提示沿用既有流式或整段 TTS，并遵循播放成功后才提交完整历史的规则。

## 配置与资源

在音箱 `/data/native_first.env` 设置：

```sh
LLM_WEB_SEARCH=auto
LLM_WEB_PLAN_TIMEOUT=8
LLM_WEB_TIMEOUT=8
```

仅作用于 `LLM_PIPELINE=native`、`BACKEND=deepseek`。每次进入 LLM 的问题增加一次结构化判断请求；需要搜索时再增加一次搜索或读取请求及资料输入 token，所以首声可能变慢。判断和检索分别默认最多 8 秒，之后最终回答仍受 `LLM_DIRECT_TIMEOUT` 约束；这不是整轮 8 秒的总预算。

官方工具使用 `DEEPSEEK_API_KEY`，仅在聊天地址为官方 DeepSeek 地址时才回用 `LLM_API_KEY`。HTTP 临时文件使用私有目录，密钥不放入搜索请求的命令行参数；返回体最多 128 KiB，拒绝损坏 JSON、NUL 和空内容。网页读取只接受会话中已有的公共 DNS 网址，拒绝 IP、localhost、内网域名和含凭据的链接；不保证受登录、反爬或站点政策限制的页面可读取。

依赖音箱已有的 `curl`、`jsonfilter`、BusyBox shell/awk。搜索与读取使用同一 DeepSeek 账户，按成功工具请求分别计费，模型判断及最终回答另计。价格和协议以 [Search/Fetch 官方指南](https://api-docs.deepseek.com/guides/search/)、[Search 接口](https://api-docs.deepseek.com/api/search/)及 [Fetch 接口](https://api-docs.deepseek.com/api/fetch/)为准。

## 关闭与维护

将实际配置中的唯一有效赋值改为 `LLM_WEB_SEARCH=off`，在音箱空闲时按[客户端操作](../runbooks/operations.md#客户端)重启，后续问题不做联网判断或搜索。此开关不关闭 DeepSeek 聊天自身所需的网络。

维护源码为 `device/lib/native_web.sh`，由开发机生成器嵌入单文件客户端。修改后执行：

```sh
python3 scripts/embed_native_web.py
./scripts/run_tests.sh
```

音箱不需要上传源模块或运行生成器。已有判停组合包必须同步活动客户端、包内客户端及 `package.sha256`，先核验其余包成员未变，再按匹配来源的备份恢复流程维护。不能单独覆盖活动脚本造成安装包与运行副本不一致。
