# DeepSeek 联网搜索

音箱 native 主线保留 `deepseek-flash`，在回答前结合同一会话决定是否搜索。搜索与网页读取使用 DeepSeek 官方接口，直接从音箱发起，不依赖 Mac；小爱原生先处理家控、闹钟、天气、报时等已有能力。

## 使用规则

| 问题 | 行为 |
|---|---|
| “帮我搜一下这家公司”“核实一下这个消息” | 搜索 |
| 现价、营业状态、比赛结果、新闻、新产品与近期变化 | 依语义搜索，不要求出现“最新” |
| “那另一款多少钱？” | 结合当前会话补全对象，重新搜索 |
| “把刚才的回答缩短” | 使用当前会话直接回答 |
| 稳定知识、创作、翻译、闲聊 | 直接回答 |
| “帮我写今天的日记”或翻译含“搜索”的引文 | 直接回答，不按词语机械触发 |
| 要求总结一个给定的公共网页链接 | 读取该网页 |
| “不要联网，解释搜索引擎” | 直接回答 |
| 缺少必要对象且上下文无法补全 | 先询问对象 |

规则通过一次非思考模式的结构化模型判断执行。判断只读取当前请求携带的会话，不检索其它会话；换话题后的新 session 不带旧上下文。语义判断并非完全确定，用户可通过“帮我联网搜索……”明确表达意图。

## 回答、来源和失败

搜索返回最多三条网页，向回答模型提供标题、网址、发表日期和摘要。指定网页提供正文；外部资料作为数据，不执行其中的命令，也不据此发起下一次工具调用。回答需要核对日期，资料不足或矛盾时应说明无法确认。

语音简短说明来源机构、网站或文章及相关日期，不要求朗读长网址；提问本身需要接口地址等网址时仍可回答。原始来源网址记录于 `/tmp/native_first_client.log` 的 `[WEB] source=` 行；不新增完整网页的持久缓存。

配置模式非法、缺 `jsonfilter`、没有可用搜索 key 或超时配置非法时，启动记录一次 `[WEB] warning … treating as off`，之后普通回答继续，不规划、不搜索、不播垫话。`on/1/true/yes` 与 `auto` 同义。

规划与 Search/Fetch 各自最多重试 `LLM_WEB_RETRIES` 次。HTTP 200 且对象校验通过返回 0；curl 6/7/28/35/52/55/56 或 HTTP 408/429/500/502/503/504 返回 10，可重试；401/402/403 返回 11；其它 HTTP 错误、超大响应、NUL、无效 JSON 返回 12，不重试。200 但规划内容不是合法路由或 `finish_reason` 不是 stop 时也不重试。网络错误/5xx 按 `LLM_WEB_RETRY_BACKOFF_MS` 退避；429 默认等 1 秒，`Retry-After` 是 ≤2 秒的整数时采用它，>2 秒直接兜底，HTTP 日期或非法头采用 1 秒。每次请求受剩余预算限制；重试还预留 0.5 秒，剩余不足 1.5 秒或退避后将不足时停止重试。

仅流式路径在规划首次失败准备重试时，或判定 search/fetch 后调用工具前，经原有 SSE/切句/TTS 流水线输出一次“搜索中，请稍等。”，上游同时继续联网。`LLM_WEB_FILLER=` 可关闭，整段回答路径不播放。垫话不作为答案 ttft，也从最终历史剥离。PCM 缓存尚未加入。

重试耗尽、空结果、无效判断或无正文时，默认追加“本轮联网判断/检索失败，未联网；涉及实时信息请明确说无法确认，不得声称查过”的 system 提示，继续请求最终回答。`LLM_WEB_FALLBACK=fail` 则只输出“暂时无法联网查询，请稍后再试。”。规划 HTTP 401/403 直接输出“大模型密钥无效，请检查配置。”，402 输出“大模型账户余额不足，请充值后再试。”，不重试、不请求最终回答；工具 401/402/403 记警告后走未联网兜底。上述固定错误提示写 `no_history`，两条回答路径都不保存它们。

只有本轮确实走过规划、最终回答传输失败且没有回答文本（或只有垫话）时，播放一次固定联网失败提示，保留失败状态、历史不变；已有部分答案或单纯 TTS 失败不补播整段错误提示。每轮 `[WEB] action=…` 汇总规划/工具耗时、次数、错误类别、是否垫话、兜底及剩余预算，不新增问题、回答、密钥或 URL query 日志。已有 `[WEB] source=` 来源日志保留。

## 配置与资源

在音箱 `/data/native_first.env` 设置：

```sh
LLM_WEB_SEARCH=auto
LLM_WEB_PLAN_TIMEOUT=4
LLM_WEB_RETRIES=1
LLM_WEB_RETRY_BACKOFF_MS=500
LLM_WEB_TOTAL_BUDGET=12
LLM_WEB_FILLER="搜索中，请稍等。"
LLM_WEB_FALLBACK=answer
LLM_WEB_TEST_FAULT=""
LLM_WEB_TIMEOUT=8
```

仅作用于 `LLM_PIPELINE=native`、`BACKEND=deepseek`。每次进入 LLM 的问题增加一次结构化判断请求；需要搜索时再增加一次搜索或读取请求及资料输入 token，所以首声可能变慢。单次判断默认 4 秒、单次工具默认 8 秒，判断、工具、退避及重试共用 12 秒总预算；最终回答单独受 `LLM_DIRECT_TIMEOUT` 约束。老配置中显式设置的超时仍保留；升级时没有配置联网搜索的用户仍默认 auto，会增加规划及可能的工具费用。配置允许值、默认值及非法值处理见[配置参考](configuration.md#联网搜索)。`LLM_WEB_TEST_FAULT` 仅测试时使用，正常运行留空，非空会在启动时醒目告警；故障类型与操作见[重试验收说明](../testing/2026-11-04-web-search-retry.md)。

官方工具使用 `DEEPSEEK_API_KEY`，仅在聊天地址为官方 DeepSeek 地址时才回用 `LLM_API_KEY`。HTTP 临时文件使用私有目录，密钥不放入搜索请求的命令行参数；返回体最多 128 KiB，拒绝损坏 JSON、NUL 和空内容。网页读取只接受会话中已有的公共 DNS 网址，拒绝 IP、localhost、内网域名和含凭据的链接；不保证受登录、反爬或站点政策限制的页面可读取。

依赖音箱已有的 `curl`、`jsonfilter`、BusyBox shell/awk。搜索与读取使用同一 DeepSeek 账户，按成功工具请求分别计费，模型判断及最终回答另计。价格和协议以 [Search/Fetch 官方指南](https://api-docs.deepseek.com/guides/search/)、[Search 接口](https://api-docs.deepseek.com/api/search/)及 [Fetch 接口](https://api-docs.deepseek.com/api/fetch/)为准。

## 关闭与维护

将实际配置中的唯一有效赋值改为 `LLM_WEB_SEARCH=off`，在音箱空闲时按[客户端操作](../runbooks/operations.md#客户端)重启，后续问题不做联网判断或搜索。此开关不关闭 DeepSeek 聊天自身所需的网络。

维护源码为 `device/lib/native_web.sh`，由开发机生成器嵌入单文件客户端。修改后执行：

```sh
python3 scripts/embed_native_web.py
./scripts/run_tests.sh
```

音箱不需要上传源模块或运行生成器。已有判停组合包必须同步活动客户端、包内客户端及 `package.sha256`，先核验其余包成员未变，再按匹配来源的备份恢复流程维护。不能单独覆盖活动脚本造成安装包与运行副本不一致。
