# S30 搜索垫话与空 Speak 交接验收

适用版本为基于 `c98023a` 的垫话修正。真人与实际时延验收 **未执行**。

## 准备

- 运行 `./scripts/run_tests.sh`。预热播放器专项覆盖派生后才入队的垫话、未授权时无播报、失败任务走普通合成，以及空 `Speak` 交接。
- 在 boot1 上成组备份和更新客户端及校验清单，启用 `LATENCY_TRACE_ENABLED=1`。搜索试题保持与基线一致。

## 步骤和预期

1. 先按 [交接验收](2026-11-06-s30-native-handoff.md)复测三条原始财经新闻问法，然后对照“现在几点”和“音量调到 30”的原生路径。
2. 覆盖 AIVS 结果 `Speak` 为空和已拦截失败播报两种情形。前者确认冻结后立即交接，后者沿用原有快速路径。
3. 搜索授权后应命中预合成垫话，客户端记录 `early filler hit`，垫话只播一次。用 `[LATENCY]` 核对 `wake→filler_commit ≤3.2s`。正文仍按原授权顺序提交。
4. 对比同一版本的提示音开关时，固定三条问题、音量及其余配置，分别记录三轮 `tts1_first` 和 `wake→answer_commit`。用单调时钟对齐 `top` 采样与合成区间，并注明漏采的短区间。

## 失败记录和恢复

保留版本、`[LATENCY]`、原始 marks、垫话命中或回退日志与实际听感。恢复上一版时成组替换活动客户端、包内副本和校验清单。A/B 结束后恢复原提示音开关。
