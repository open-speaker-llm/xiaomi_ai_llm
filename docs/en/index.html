Xiaomi XiaoAI speaker LLM

A client on the Xiaomi AI Speaker MDZ-25-DA (S12A). Native XiaoAI still handles lights, weather and similar commands. Open questions go to a cloud LLM the speaker calls directly, and online EdgeTTS speaks the answer. The model does not run on the speaker, and the LLM path does not work offline.

小米 AI 音箱 MDZ-25-DA（S12A）上的客户端。开灯、天气仍走小爱，开放问题直连云端大模型。不是离线方案，也不是小米官方产品。

Demo

The same speaker: XiaoAI turns on a light, DeepSeek answers, then a follow-up without the wake word. Follow-up without the wake word needs its component installed. No timing figures are attached to this clip.

How it works

  1. Wake XiaoAI. Speech recognition stays on Xiaomi's cloud.
  2. The on-speaker client chooses native XiaoAI or the LLM.
  3. The speaker calls your cloud LLM by default. On-device streaming signals takeover with “dong-dong” and a green light. On the DeepSeek path, web search first says “搜索中，请稍等。” (Searching, please wait).
  4. EdgeTTS speaks the answer, with native XiaoAI TTS as a fallback.
  5. After a complete answer, a single “dong” signals the end. With boot1 real-time follow-up installed and enabled, listening resumes after the cue with a steady green light; continue without the wake word. Silence ends it. The five spoken exit phrases are off by default.

The green light already existed. Audio cues and search filler are included in PR #17, merged on 2026-11-06. See configuration for LLM_ROUTE_BEEP, LLM_END_BEEP, and LLM_WEB_FILLER. Firmware-managed native_multirounds skips the end cue.
